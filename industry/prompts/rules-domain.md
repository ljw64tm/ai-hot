
【心理学与行为科学领域翻译规则 — 本站核心方向是人工智能与经济决策，严格遵守】

1. 歧义默认值：以下词在中文有非心理学歧义，**一律按心理学含义翻译**：
   - Attachment = 依恋（绝不译"附件"/"附着"）
   - Attachment style = 依恋类型（不译"附件样式"）
   - Bias = 偏差；统计与方法语境按"偏倚"（如 selection bias = 选择偏倚）
   - Depression = 抑郁（绝不译"萧条"/"经济衰退"）
   - Anxiety = 焦虑
   - Stress = 压力 / 应激（心理压力与生理应激按语境选，同一篇内保持一致）
   - Mindfulness = 正念
   - Resilience = 心理韧性（不译"弹性"/"恢复力"）
   - Validity / Reliability = 效度 / 信度（不译"有效性"/"可靠性"）
   - Effect size = 效应量
   - Cohort = 队列（cohort study = 队列研究，不译"群体"）
   - Placebo = 安慰剂
   - Randomized controlled trial = 随机对照试验
   - Meta-analysis = 元分析
   - Confounder = 混杂因素
   - Prevalence / Incidence = 患病率 / 发病率（不混用）
   - Screening = 筛查（不译"筛选"/"检测"）
   - Stigma = 污名
   - Burnout = 职业倦怠（不译"烧毁"/"燃尽"）

1b. 决策与经济决策方向（本站核心方向）的术语，按下列固定译法，同一篇内保持一致：
   - Ambiguity aversion = 模糊厌恶（不译"歧义厌恶"）
   - Loss aversion = 损失厌恶
   - Framing effect = 框架效应（不译"框架作用"/"框定效应"）
   - Anchoring = 锚定（anchoring effect = 锚定效应）
   - Endowment effect = 禀赋效应
   - Present bias = 现时偏差
   - Delay discounting = 延迟折扣
   - Prospect theory = 前景理论（不译"展望理论"）
   - Nudge = 助推
   - Algorithm aversion = 算法厌恶（不译"算法反感"/"反算法"）
   - Automation bias = 自动化偏差
   - Algorithmic fairness = 算法公平（不译"算法公正性"）
   - Human-in-the-loop = 人在回路
   - Treatment effect = 处理效应（不译"治疗效果"，治疗语境才用"疗效"）
   - Effect size = 效应量（同第 1 条，决策研究中同样适用）
   - Pre-registration = 预注册
   - Replication = 重复验证（不译"复制"/"复现"）
   - Field experiment = 现场实验
   - Vignette = 情境实验材料（vignette study = 情境实验研究，不译"小插曲"）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 诊断手册与分类：DSM-5-TR / ICD-11
   - 量表缩写（举例 + 通用规则）：PHQ-9 / GAD-7 / PCL-5 / MMPI / WAIS / WISC / Big Five / NEO-PI-R
     **规则**：任何量表、问卷、诊断工具的缩写一律保留英文，不自行译成中文全称
   - 疗法缩写：CBT / DBT / ACT / EMDR / MBCT
     **规则**：疗法缩写保留英文，必要时在首次出现处补一次中文全称，后续保持一致
   - 统计与方法缩写：RCT / meta-analysis / CI / OR / HR / NNT / p 值（小写斜体 p，保留 "p<0.001"、"p = .03" 等原文写法）
     **规则**：任何 2-5 字母的全大写缩写，默认按心理学与统计含义保留英文
   - 脑成像与神经科学缩写：fMRI / EEG / tDCS / TMS
   - 机构与期刊名：APS / Nature Human Behaviour / Nature Machine Intelligence / Journal of Economic Psychology / Psychological Science / PLOS ONE / Frontiers in Psychology / PsyPost
     **规则**：机构名、期刊名、学会名一律保留英文原文，不加中文括注；中文期刊《心理学报》按中文原名写

3. 中国机构**优先用官方中文名**（首次出现可双标"中国科学院心理研究所（Institute of Psychology, CAS）"，后续选一种保持一致）：
   - 中国科学院心理研究所（中科院心理所）/ 北京大学 / 北京师范大学 / 中国心理学会 / 国家心理健康和精神卫生防治中心
   - 人名、医院名、学校名以原文给出的写法为准：原文只有英文且无通行中文名的，保留英文，不自行音译或编造机构名

4. 数字与单位 **一字不改**保留：
   - 样本量：N=1,024、n=37（绝不改写成"一千多名被试"）
   - 年龄与描述统计：M=24.3, SD=4.1、年龄范围 18–65 岁
   - 效应量与置信区间：d=0.42、OR=1.8（95% CI 1.2–2.6）、HR=0.71
   - p 值与显著性：p<0.001、p = .03
   - 百分比、比率、患病率、量表分数与临界值：17.3%、12 个月复发率 24%、PHQ-9 ≥ 10
   - 不要把 "d=0.42" 改写成"中等效果"，不要把 "OR=1.8" 改写成"风险明显更高"；换算或解释只能原样引用原文已有的说法

5. 不过度推广：译文必须保留原文限定的被试与结论范围
   - 被试是动物、学生、临床样本、社区样本或网络样本时，必须写明是哪一类，不得隐去成"人们""大众"
   - participants / patients / respondents 要区分：被试 / 患者 / 受访者，不一律译成"参与者"
   - 不得把 "associated with" / "linked to" 译成"导致"；相关就是相关，因果只有原文写了 cause 才写因果
   - 原文写 'may'、'suggests'、'preliminary' 时，译文保留"可能""提示""初步"这类限定，不得升级为"证明""表明必然"
   - AI 相关研究必须区分"模型在数据集上的表现"与"人在使用它之后的决策结果"：accuracy、AUC、benchmark 只能译成模型表现，不得写成决策质量提升、决策更准确或人因此获益；原文若只报告模型指标，译文就只报告模型指标
