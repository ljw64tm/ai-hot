## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于提出、试验、发表、实施还是复盘阶段”。然后从以下 12 类中选择最贴近的一类：

- `decision_study`：以人的判断与选择为对象的实验或实证研究，含行为实验、选择实验、现场实验与助推
- `ai_decision_study`：把机器学习、大模型或算法放进决策场景的研究，含算法建议与人机协作、自动决策的信任与依赖、算法厌恶与公平感知、AI 生成信息的说服与操纵、AI 对劳动与消费决策的影响
- `ai_sycophancy_study`：以模型的迎合、附和或过度肯定为对象的研究，或研究人对被迎合的反应
- `conspicuous_consumption_study`：以地位性、炫耀性或奢侈品消费为对象的研究
- `clinical_trial`：干预、治疗或预防的效果研究，含随机对照试验、队列与真实世界研究
- `assessment_instrument`：量表、诊断工具或测量方法的编制、修订与验证
- `practice_method`：可以直接照着做的方法、方案、练习或操作经验
- `research_paper`：以新发现、机制或理论解释为核心的心理学研究
- `industry_event`：政策、监管、机构举措、资金项目、执业与服务行业事件
- `review_or_guideline`：元分析、系统综述与临床指南
- `opinion_analysis`：观点、判断、批评、复盘或长访谈
- `explainer`：科普、术语与现象解读、辟谣

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在心理学知识与实践的时间线上是节点、这周值得知道的变化，还是当天脚注。不要把“普通人能马上用”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。新的效应、新的机制解释、新的疗效对照、新的人群或新的方法才是增量；换个说法复述已知结论不是。
3. `cred` 证据强度：材料内部对核心结论提供了多强的支持，不是来源名气。要看设计、样本、对照、效应量与是否被过度推广。期刊名气、机构名气、样本量大都不能自动证明结论成立。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关，或至少能理解它为何重要、反常、好玩。
5. `act` 可用性：读者是否能马上使用、学习、调整做法或迁移到自己的场景。纯新闻和重大发现的 act 低是正常的，不应反过来抹掉 sig。

## 品味规则

### 必须正常评价的价值

- 结论会改变从业者或普通读者对某种做法、能力边界或人群判断的研究，按真实份量正常评分：疗效对照、有效成分、风险因素、干预可及性、诊断与分类的实质变化。
- 大样本人群研究、长期追踪、预先注册的重复验证，以及推翻或明显削弱既有结论的结果，即使结论不“好用”，也应按证据价值正常评分。
- 能立即照着做的方法、方案和操作经验，只要具体、清楚、对读者有用，即使不是学科大事也可以很高。
- 新量表或测量方法的可靠验证、跨人群常模、明显更短或更易实施的测量方式。
- 决策与经济决策方向按真实份量正常评分：大样本或预注册的决策实验、能改变对某类干预或政策判断的效应、算法建议与人机协作的可迁移结论、跨人群的异质性结果，以及把 AI 用在测量与预测上的方法验证。
- AI 谄媚与炫耀性消费按真实份量正常评分：可复现的迎合行为测量、能被读者对照自己使用经历的结果、地位性消费的动机与代价研究，以及品牌或平台策略对普通消费者影响的实证结论。
- 心理健康政策与服务的实质变化、真实的服务事故与可验证的行业事件。
- 普通人能理解的重大医学、教育、法律或社会结果，只要心理学对方法或结论不可替代地重要，就按现实注意力价值判断。
- 可信的新事实、反直觉结果、人物信号、学科冲突或文化反差，只要普通读者一眼能理解“为什么有意思”，可以形成独立高价值。

### 必须压住的噪声

- 把相关性写成因果、把动物或小样本结果写成人人适用的结论：`cred ≤ 3`，`sig ≤ 4`，不得因为期刊或机构名气豁免。
- 单个未重复的小样本实验、被试量很小或没有对照的“新发现”：`sig ≤ 4` 且 `nov ≤ 4`。
- 用心理学名词包装的营销软文、课程推广、付费测评推广、机构招生、活动报名，以及用 AI 作为卖点的产品软文与课程推广：`sig ≤ 2`。
- 只有模型准确率或 benchmark、没有关于人的行为或决策结论的论文，以及没有行为数据的纯算法论文：`sig ≤ 3` 且 `reson ≤ 3`。
- 把实验室里的小样本、短期效应写成现实世界的决策改善，或把“模型预测准确率”写成“决策质量提升”：`cred ≤ 3` 且 `sig ≤ 4`。
- 只把既有结论换个说法再讲一遍、没有新证据的科普与专栏：`nov ≤ 3`。
- 拿一段模型对话截图或一次用户体验就断言“AI 在讨好所有人”，或把炫耀性消费只当成道德批判、没有行为数据或样本说明的稿件：`cred ≤ 3` 且 `sig ≤ 4`。
- 情绪鸡汤、励志话术、“测测你的性格”、榜单式心理测试娱乐内容：`sig ≤ 2`。
- 名人在访谈里顺口说的心理判断、没有研究与数据的观点：`nov ≤ 3` 且 `cred ≤ 3`。
- 多篇研究打包的综述性新闻、早报周报式汇总且没有单一焦点：`sig ≤ 3`。
- 脑区激活、生物标志物或单一机制的小幅推进，默认 `sig ≤ 4` 且 `reson ≤ 3`；不能因为技术先进、机构知名或数字很多自动豁免。
- 宏大观点若没有新事实、新因果或可复用框架；机构成立、预算公布、人事任命若没有已兑现后果；仅仅“心理学说”的趣闻，均应明显低分。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一项研究或同一个事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或适用人群补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强的故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用、是否来自名刊，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 广泛适用性本身是实质变化。一个已经反复验证的做法，若在新人群、新场景或大规模实施中得到明确效果，这是结论适用范围的变化；即使材料是短引用，也不能按“个人二手体验”或“普通转发”压低 `sig`、`nov`、`reson`。
3. 元分析或系统综述把多项研究合起来，给出比任何单项研究都更可靠的结论，或明确指出效果不存在时，应按学科节点的份量判断，不得因为“只是综述”压成汇编。
4. 同一材料同时包含一个强证据和一个弱叙事时，以强证据为核心分类和评分；弱叙事不能把强结果降格。例如“随机对照试验 + 一段被试轶事”“指南更新 + 一位专家的评论”。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一内部指标、机构宣传或宏大推断制造事件价值。只有正文支持的新事实、适用范围变化或可迁移方法进入五轴。
6. 心理学常见的措辞膨胀必须还原：媒体式的“证明”“彻底改变”“人人都该知道”不提高分数；原文只说相关时不得按因果给分；原文只有学生或网络样本时不得按一般人群给分。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
